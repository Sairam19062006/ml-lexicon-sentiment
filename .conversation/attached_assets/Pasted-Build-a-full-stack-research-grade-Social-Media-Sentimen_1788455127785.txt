Build a full-stack, research-grade Social Media Sentiment Analysis web application named "Sentinel AI" using Node.js/Express (or Python FastAPI) for the backend and HTML5/Tailwind CSS/Chart.js for the frontend.

PROJECT OVERVIEW:
Application Name: Sentinel AI
Subtitle: Machine Learning & Lexicon-Based Social Media Intelligence
Description: A hybrid NLP analytics platform that evaluates social media text using both Machine Learning algorithms (Logistic Regression, Naive Bayes, Support Vector Machine) and Lexicon-Based engines (VADER, TextBlob).

CORE FEATURES & REQUIREMENTS:

1. DASHBOARD PAGE:
- Stat Cards: Total Analyzed Posts (24,680), Positive (13,842 / 56.1%), Negative (5,426 / 22.0%), Neutral (5,412 / 21.9%).
- Dynamic Charts: 
  * Sentiment Distribution (Doughnut Chart)
  * Weekly Sentiment Trend (Line Chart)
  * Platform Breakdown Bar Chart (Instagram, X/Twitter, Facebook, Reddit, YouTube)
- Live Signal Feed showing recent sentiment spikes and alert clusters.

2. ANALYZE TEXT PAGE (Interactive NLP Testing):
- Modern dark-theme text editor where users can input social media comments/tweets.
- Model Selection Dropdown:
  * Logistic Regression (Supervised ML)
  * Multinomial Naive Bayes (Supervised ML)
  * Support Vector Machine (SVM) (Supervised ML)
  * VADER Lexicon Engine (Rule-Based)
  * TextBlob Polarity Engine (Rule-Based)
- "Run Classification" Button that processes the text and displays:
  * Predicted Sentiment Label (Positive / Negative / Neutral)
  * Confidence Score / Polarity Percentage with an animated progress bar
  * Explanation Panel highlighting key positive/negative keywords found in the input.

3. DATASET UPLOAD PAGE:
- Drag-and-Drop file uploader accepting CSV, XLSX, and JSON files up to 25MB.
- Shows dataset preview table upon upload with columns: ID, Text, Platform, Predicted Sentiment, Confidence Score.

4. PERFORMANCE EVALUATION PAGE:
- Model Benchmark Comparison Cards:
  * Logistic Regression (Accuracy: 92.4%, Precision: 91.8%, Recall: 90.7%, F1: 91.2%)
  * Naive Bayes (Accuracy: 89.7%, Precision: 88.9%, Recall: 89.4%, F1: 89.1%)
  * Support Vector Machine (Accuracy: 88.9%, Precision: 89.2%, Recall: 87.8%, F1: 88.5%)
  * VADER Lexicon (Accuracy: 84.6%, Precision: 83.7%, Recall: 82.9%, F1: 83.3%)
  * TextBlob Lexicon (Accuracy: 80.3%, Precision: 79.8%, Recall: 78.6%, F1: 79.2%)
- Radar Chart or Bar Chart comparing Accuracy vs F1-Score across all 5 models.

5. ANALYTICS & WORD CLOUD PAGE:
- Keyword frequency distribution (Word Cloud visualization).
- AI Highlights: Most Positive Topic ("Product Experience"), Most Negative Topic ("Customer Support"), Trending Keyword ("Update").

6. SYSTEM ARCHITECTURE & ABOUT PAGE:
- Step-by-step workflow visualizer: Data Ingestion -> Preprocessing (Tokenization, Stop-words) -> TF-IDF Vectorization / Lexicon Lookup -> Classification -> Analytics Dashboard.
- Project Metadata: Lead Developer (Sairam M S), B.Tech IT, Linux Mint environment.

DESIGN & UI SYSTEM:
- Dark Theme Theme (#0F172A background, #1E293B card background).
- Accent Colors: Blue (#3B82F6), Indigo (#6366F1), Success Green (#22C55E), Danger Red (#EF4444).
- Glassmorphic card styling, FontAwesome icons, responsive sidebar layout, and smooth animations.

BACKEND / LOGIC REQUIREMENTS:
- Implement a functional API endpoint `/api/analyze` that accepts text and model choice, returning sentiment, confidence score, and extracted keywords.
- Implement an API endpoint `/api/upload` to handle CSV parsing and return simulated batch classification results.
- Serve the frontend cleanly through express static routes.
